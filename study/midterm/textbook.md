# 教材九章 Typst 复习精编

本版复习资料依据《数字集成电路分析与设计——深亚微米工艺（第三版）》的**九章章节结构**重新组织教学知识，结合已有 HSPICE 实验提供核心概念、公式及自检题。它是**原创复习提纲，不是对教材原文的逐字重排或扫描页复制**。

教材上传版本为 445 页扫描 PDF，目录可以确认下列章节题名与起始印刷页码；由于扫描正文缺少可靠可提取文本，公式与应用说明按课程知识重新表述。原教材中的具体例题、图号、工艺参数仍应回到教材对应页核验。

## 复习路径建议

*基础路径（对照实验一至九）：*第 1、2、3 章建立符号与器件概念，第 4、5 章完成反相器、CMOS 门与时序结构，第 6、7 章用于理解瞬态延迟和 MOS 传输特性。

*拓展路径：*第 8、9 章讨论存储器；只有在授课安排覆盖时才应作为期中考试重点。它们作为整本教材的知识地图保留，便于后续学习。

每个章节的 Typst 源文件均位于仓库的 [textbook/units 目录](https://github.com/stevessr/hspice/tree/main/study/midterm/textbook/units)，可按章节独立维护。PDF 在独立 GitHub Actions 中生成并发布，网站与 PDF 编译互不阻塞。
