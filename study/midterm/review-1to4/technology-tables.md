# 制造工艺、版图、模型和计算数据表（详解）

此专题集中整理原书第2、3章涉及的物理与工艺信息，连接到第4章的反相器设计。**表中凡出现数值示例，均以教学假设为准**；不同工艺节点、PDK、工艺角的精确值必须查相应库与设计规则文件。

## 1. 从材料到芯片：工艺流程

| 步骤 | 目的与输入 | 关键产物及器件影响 | 常见风险/检查点 |
|---|---|---|---|
| 单晶硅衬底与外延 | 提供晶体基础和可控掺杂 | p型/n型体区、外延层 | 晶格缺陷、掺杂均匀性 |
| 热氧化 | 在硅表面形成SiO₂介质 | 栅氧化层、隔离氧化层（依工艺而异） | 厚度、界面态、栅漏电 |
| 薄膜沉积（CVD/PVD/ALD） | 加入绝缘、半导体或导电材料 | 介质、栅材料、阻挡层、金属层 | 膜厚、覆盖率、应力 |
| 涂胶/对准/曝光/显影 | 将掩模图案转入光刻胶 | 定义栅、扩散区、接触孔、互连图形 | 对准偏差、线宽粗糙 |
| 刻蚀（干/湿） | 选择性去除暴露材料 | 控制栅边界、孔洞和互连形状 | 过刻、侧壁、选择比 |
| 离子注入 | 按区域调节载流子与阈值 | 阱、源漏、LDD/halo等（取决于技术） | 剂量、深度、损伤 |
| 退火/快速热处理 | 激活掺杂并修复晶格 | 形成电学有效结和沟道轮廓 | 扩散增量、结深 |
| STI 隔离 | 隔离相邻器件的有源区域 | 浅沟槽氧化物 | 寄生耦合、应力 |
| CMP 平坦化 | 为后续光刻恢复平整表面 | 平坦介质与金属图形 | 过抛、侵蚀和局部形貌 |
| 接触孔/通孔与互连 | 将晶体管连接成电路 | Contact、Via、M1—Mn | 接触电阻、RC、EM |
| 钝化、晶圆测试、封装 | 保护、连接和筛选电路 | 可用芯片及封装引线 | 良率、可靠性、封装寄生 |

*顺序提示：* 这是帮助记忆的模块化工序清单，不意味着完整芯片只执行一轮氧化、光刻、注入或金属沉积。真实CMOS工艺使用重复且受约束的步骤组合。

## 2. 版图图层与器件关系

| 层或结构 | 典型作用 | 对器件或计算的影响 |
|---|---|---|
| P-substrate / P-well | NMOS体区 | $V_{SB}$、体效应、寄生结 |
| N-well | PMOS体区 | 体连接、电隔离、寄生结 |
| Active / Diffusion | 定义源漏和沟道所在的有源硅 | 结面积与侧壁寄生 |
| Gate / Poly | 与有源区交叠形成栅控制区 | 绘制$L$、栅宽$W$、重叠电容 |
| STI | 分隔相邻有源区 | 漏电、应力与可制造性 |
| Contact | 扩散或栅与第一层金属接点 | 接触电阻，接点个数 |
| Metal 1…n | 局部与全局布线 | 方块电阻、互连寄生、IR Drop |
| Via | 相邻金属层之间连接 | 通孔电阻与电迁移可靠性 |
| Implant / Select | 控制掺杂类型与浓度 | NMOS/PMOS及阈值变化 |
| Passivation / Pad | 顶层保护和外部连接 | ESD、封装与测试接口 |

## 3. 几何设计规则

| 名称 | 说明 | 不满足的后果 |
|---|---|---|
| 最小线宽 | 同一层图形能可靠制造的最小宽度 | 断线、线宽偏差 |
| 最小间距 | 同层图形间应保持的最小距离 | 意外短接或良率下降 |
| Enclosure 包围 | 某层须在另一层边缘外保留的余量 | 接触或通孔漏接 |
| Extension 延伸 | 图形必须超出另一层一定距离 | 有效栅或连接不可靠 |
| Contact/Via 尺寸 | 孔尺寸和周边围栏要求 | 接触电阻过大、开路 |
| Well spacing | 阱与阱之间的间隔要求 | 隔离和闩锁风险 |
| Density 密度约束 | 金属和介质填充比例 | CMP不均匀、寄生变化 |

例如 $\lambda=0.05\,\mu m$ 的假想规则给出最小线宽 $3\lambda=0.15\,\mu m$、间距 $2\lambda=0.10\,\mu m$。**以上倍数仅是题设示例，不能用于真实版图签核。**

## 4. MOS参数及其物理意义

| 符号 | 量纲 | 意义 | 特别注意 |
|---|---|---|---|
| $W$ / $L$ | m、μm | 沟道宽度 / 有效或绘制长度 | 长沟道$\beta\propto W/L$ |
| $t_{ox}$ | nm | 栅介质厚度 | 影响$C_{ox}$和栅泄漏 |
| $\epsilon_{ox}$ | F/m | 栅介质介电常数 | $C_{ox}=\epsilon_{ox}/t_{ox}$ |
| $C_{ox}$ | F/m² | 单位面积氧化层电容 | 不等于总$C_{gs}$ |
| $\mu_n,\mu_p$ | m²/(V·s) | 载流子迁移率 | 偏置/温度/垂直场可变 |
| $V_T$ | V | 阈值电压 | 随体偏置、尺寸和温度变化 |
| $\gamma$ | $\sqrt V$ | 体效应系数 | 常用于长沟道阈值模型 |
| $\phi_F$ | V | 费米势 | 掺杂、温度相关 |
| $E_c$ | V/m | 临界电场 | 短沟道速度饱和 |
| $\lambda$（电流模型） | 1/V | 沟道长度调制 | 不等于版图尺寸比例$\lambda$ |
| $R_\square$ | Ω/□ | 方块电阻 | $R=R_\square\ell/W$ |

## 5. CMOS器件模型与仿真精度

| 模型/方法 | 用途 | 可描述的典型特征 | 不能直接推断 |
|---|---|---|---|
| 理想开关模型 | 功能逻辑、概念电路 | 导通/关断的逻辑关系 | 精确功耗与延迟 |
| SPICE LEVEL 1 | 长沟道教学、电流方程验证 | 一阶$I_D$、阈值、体效应、$\lambda$ | 先进工艺的完整短沟道行为 |
| BSIM3 | 深亚微米工艺器件仿真 | 迁移率退化、DIBL、速度饱和、亚阈值及几何效应 | 未经PDK/参数文件不能给出真实数值 |
| 版图后PEX | 含互连寄生的时序/功耗评估 | 提取R/C、耦合和载荷 | 仅靠 schematic 不能代替PEX |
| 多角PVT仿真 | 制程/电压/温度覆盖 | 最差时序、功耗及噪声分析 | 单一TT点不是最差情况 |

## 6. PVT角落表

| 维度 | 常见设置 | 需要回答的设计问题 |
|---|---|---|
| Process | TT、FF、SS；也可能有FS/SF | n/p器件强弱及不对称影响 |
| Voltage | VDD标称、低压、高压 | 延迟、噪声容限、功耗如何变化 |
| Temperature | 冷、常温、热 | 迁移率/阈值/亚阈值漏电变化 |
| Load | 负载电容、扇出、输入斜率 | 关键路径瓶颈 |
| Variation | Monte Carlo、mismatch（有PDK时） | 统计裕量与可制造性 |

**原则：** 不存在保证所有指标都由“SS+低压+高温”组合统治的通用法则；对每个指标分别比较各角条件。

## 7. DRC、LVS、PEX、仿真对比

| 阶段 | 输入 | 输出 | 关键问题 |
|---|---|---|---|
| DRC | 版图与规则文件 | 几何违规清单 | 能不能制造 |
| LVS | 原理图网表+版图抽取网表 | 结构/器件匹配报告 | 连接是否一致 |
| PEX | 版图、提取规则 | 带寄生R/C的网表 | 真实互连带来多大延迟 |
| DC分析 | 网表+模型角 | 偏置点/VTC | 输出逻辑电平和阈值是否满足 |
| TRAN分析 | 网表+激励 | 波形与延迟 | 边沿、功耗、竞争/毛刺如何 |
| PVT | 多套模型/供电/温度 | 最差情况集合 | 是否所有约束通过 |
