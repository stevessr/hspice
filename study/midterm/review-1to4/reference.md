# 跨章公式与考前速查

## A. 公式总表

| 分类 | 核心式 | 适用范围 |
|:--|:--|:--|
| 噪声容限 | $NM_L=V_{IL}-V_{OL}$；$NM_H=V_{OH}-V_{IH}$ | 静态VTC |
| 平均延迟 | $t_p=(t_{pHL}+t_{pLH})/2$ | 50%电压点 |
| RC延迟 | $t\approx0.69R_{eq}C_L$ | 一阶近似 |
| 动态功率 | $P=\alpha CV_{DD}^2f$ | $\alpha$ 表示0→1次数/周期 |
| 氧化层电容 | $C_{ox}=\varepsilon_{ox}/t_{ox}$ | 单位面积 |
| 体效应 | $V_T=V_{T0}+\gamma(\sqrt{2\phi_F+V_{SB}}-\sqrt{2\phi_F})$ | 通常NMOS反向体偏置 |
| 线性区电流 | $I_D=\beta[(V_{GS}-V_T)V_{DS}-V_{DS}^2/2]$ | 长沟道NMOS |
| 饱和区电流 | $I_D=\beta(V_{GS}-V_T)^2/2$ | 长沟道，忽略$\lambda$ |
| 工艺方块电阻 | $R=R_{\square}\ell/W$ | 均匀薄膜 |
| 电阻负载节点 | $(V_{DD}-V_o)/R_L=I_D$ | 直流KCL |
| CMOS切换电压 | $V_M=(V_{Tn}+r(V_{DD}-|V_{Tp}|))/(1+r)$ | 双管饱和，$r=\sqrt{\beta_p/\beta_n}$ |
| 三态门 | $EN=0\Rightarrow Y=Z$ | 具体使能极性以题目为准 |

## B. 公式使用前的五个检查

1. **单位：** $\mu A/V^2$、$fF$、$k\Omega$、$ns$ 必须统一；$1\,k\Omega\cdot1\,fF=1\,ps$。
2. **端电压：** $V_{GS}$ 不是 $V_G$；$V_{DS}$ 不是 $V_D$；阈值可能受体效应影响。
3. **模型：** 平方律是长沟道模型，不能默认为BSIM3的全部行为。
4. **工作区：** $V_{DS}$ 与 $V_{OV}$ 的比较决定能否采用线性/饱和公式。
5. **负载：** 电容负载影响动态过程，电阻/晶体管负载可改变静态工作点。

# 复习验收：一眼识别六种错误

1. **把 $V_G$ 误作 $V_{GS}$：** 先算源电压，再算栅源差。
2. **不验证工作区：** 解得电流/输出电压后，检查线性或饱和不等式。
3. **把 $\beta$ 与 $k'$ 混淆：** $\beta=k'W/L$，单位均为 $A/V^2$，但数值不同。
4. **把SSNM理解为瞬态抗扰度：** 静态VTC裕量不等于动态脉冲可容许幅值。
5. **把栅面积电容当作总负载：** 实际有重叠、结和互连寄生。
6. **把仿真电源电流符号误认成NMOS负电流：** 先确认SPICE的源电流参考方向。
