# 第3章 制造、版图和模拟

## 3.1 IC制造工艺总览

教材3.2节讨论从晶圆到芯片的主要制造步骤。理解其作用与大体顺序，比机械记住全部细节更重要：

1. **基底与薄膜形成：** 氧化、沉积介质/半导体/金属薄膜。
2. **光刻：** 涂胶、对准、曝光、显影，把掩模图形转移到光刻胶。
3. **刻蚀与注入：** 在指定区域刻蚀材料或利用离子注入改变掺杂。
4. **退火和热处理：** 激活掺杂、修复损伤、控制扩散。
5. **绝缘、接触与多层互连：** 形成接触孔、通孔、金属层及介质隔离。
6. **测试与封装：** 晶圆测试、切割、封装、成品测试。

工艺实际由多个沉积—光刻—刻蚀—掺杂—平坦化循环组成，不能把上述概述误解为每一步只执行一次。

## 3.2 CMOS结构和基本版图层

CMOS工艺一般同时形成NMOS与PMOS。NMOS通常位于p型区域，PMOS位于n阱或相应n型区域。隔离结构（如STI）、多晶硅/栅结构、源漏扩散区、接触孔、金属层与通孔共同组成电路。

MOS沟道一般位于**栅跨过有源区**的位置。栅宽 $W$ 通常对应沟道横向宽度，栅长 $L$ 是电流从源到漏穿过的沟道方向长度。简单版图面积不能直接等同于 $WL$，因为源漏扩散、接触间距和金属走线也占空间。

## 3.3 版图设计规则与比例规则

版图规则用于保证可制造性，例如最小线宽、最小间距、包围（enclosure）、延伸（extension）、接触尺寸等。教材3.3节介绍比例化规则和$\lambda$表达法。

若一个工艺规定 $\lambda=0.05\,\mu m$，那么规则“线宽不小于 $3\lambda$”就是线宽至少 $0.15\,\mu m$；“间距不小于 $2\lambda$”就是至少 $0.10\,\mu m$。这里的 $\lambda$ 是**版图尺度参数，不是沟道长度调制参数**，两者只有符号相似。

- **DRC：** 检查版图是否满足几何设计规则。
- **LVS：** 比较版图提取出的电路连接关系与原理图/网表是否一致。
- **PEX：** 提取寄生电阻和寄生电容，用于后仿真分析。

本章原书重点是基本版图、器件模型和制造；此处将DRC/LVS/PEX整理为常用工程术语，帮助理解版图—仿真的联系。

## 3.4 金属互连与寄生RC

均匀导体电阻：

$$R=\rho\frac{\ell}{tW}=R_{\square}\frac{\ell}{W},\qquad R_{\square}=\frac{\rho}{t}.$$

其中 $R_{\square}$ 单位为 $\Omega/\square$，$\ell/W$ 是“方块数”。金属线越长越窄，电阻越大；边缘电容、层间耦合电容和电容到衬底的贡献需要根据版图和工艺判断。

对平行板的粗略估计：

$$C\approx\varepsilon\frac{A}{d}.$$

**算例：** $R_{\square}=0.08\,\Omega/\square$，金属线长 $100\,\mu m$、宽 $0.5\,\mu m$，则 $R=0.08(100/0.5)=16\,\Omega$。若对应集中负载为 $10\,fF$，单一RC时间常数只有 $0.16\,ps$，但分布RC延迟还要考虑位置和实际耦合环境。

## 3.5 SPICE和HSPICE：电路描述与器件模型

书中3.4—3.6节区分**器件模型**与**电路级求解**。SPICE通过节点网络、元件参数、模型方程与分析命令构成方程组；结果取决于模型精度、偏置和分析类型。

**MOS元件的基本语法（按本书和常用HSPICE）：**

```text
Mname  Drain  Gate  Source  Bulk  Model  L=... W=...
```

不能把节点顺序误写为G-D-S-B。名称以 `M` 开头代表MOS器件；`X` 往往用于子电路实例，因此模型库如果用 `.SUBCKT` 包装器件，需要采用 `Xname` 调用并按照子电路引脚声明的顺序连接。

下面给出**独立的教学用LEVEL 1模型示例**，不依赖外部工艺库，可用来学习电流曲线的形成；它不是0.18μm工艺的准确代工厂模型：

```spice
* Long-channel NMOS demo
.option post=2
.model NTEST NMOS (LEVEL=1 VTO=0.4 KP=200u LAMBDA=0)
VGS g 0 DC 0.8
VDS d 0 DC 0
M1 d g 0 0 NTEST L=1u W=5u
.dc VDS 0 1.2 0.02 VGS 0.6 1.2 0.2
.print dc I(VDS)
.end
```

**注意：** $I(VDS)$ 是流入理想电压源正端的电流，漏极由该电源供电时通常为**负值**，因此绘制正的NMOS漏电流可使用 $-I(VDS)$。用于课程中的 `.lib '...c18vmos001.lib' TT` 一类模型库时，还须检查其器件名是 `.model` 还是 `.subckt`，以及TT/FF/SS等角落是否真实存在。

常见分析：

| 命令 | 任务 | 应理解的横轴 |
|:--|:--|:--|
| `.op` | 求直流工作点 | 无扫描横轴 |
| `.dc` | 扫描电压/电流源 | 被扫源的值 |
| `.tran` | 瞬态响应 | 时间 $t$ |
| `.ac` | 小信号频率响应 | 频率 $f$ |
| `.measure` | 数值测量（语法随分析不同） | 由测量类型指定 |

**常见错误：** 忘记 `.end`、子电路引脚顺序不匹配、源体端颠倒、工艺库路径错误、模型角落不存在、器件尺寸单位误写、用DC分析期望看到随时间变化的输出。

## 3.6 LEVEL 1与BSIM3模型

**LEVEL 1：** 以简单MOS方程为基础，参数少、便于理解。书中列出阈值 $VTO$、跨导参数 $KP$、体效应 $GAMMA$、沟道长度调制 $LAMBDA$ 等；适合课堂推导，不适合全面预测深亚微米器件细节。

**BSIM3：** 原书3.6节详细讨论基于表征数据拟合的深亚微米模型，包含短沟道阈值修正、迁移率退化、饱和行为、亚阈值电流、寄生电容和寄生电阻等。实际模型还涉及工艺角、温度、尺寸有效值和参数提取过程。

正确认识模型层次：

- 同样的 $W/L$，LEVEL 1与BSIM3结果并不一定相同。
- 同样的 $W$ 和 $L$，改变温度、$V_{DD}$、工艺角会得到不同波形与时序。
- 参数提取不应靠单个测量点：要用多种 $V_{GS}$、$V_{DS}$、尺寸和温度条件校验。
- 工艺模型一般由测量与标定得来，不应为了匹配一道习题随意改动官方模型库。

## 3.7 PVT、版图后仿真与分析次序

**PVT = Process / Voltage / Temperature：** 工艺、供电电压、温度三个变量可能同时影响速度、泄漏与电平。原书3.7节还讨论温度、电源和电压极限等附加效应。

建议分析流程：

1. 使用简单LEVEL 1或公式验证数量级与工作区。
2. 使用真实工艺模型进行直流扫描，验证 $V_T$、$I_D$ 和 $V_{Dsat}$ 趋势。
3. 构造反相器/逻辑门，进行VTC和瞬态分析。
4. 加入明确负载电容，改变输入斜率和器件尺寸。
5. 引入版图提取寄生与PVT条件，比较变化原因。

在教材示例中的0.18/0.13μm参数只是历史工艺学习案例，不应当作当前先进工艺的准确PVT结论。

## 3.8 本章检查点

1. 能说明光刻、刻蚀、离子注入、氧化/沉积、互连各自的作用。
2. 能在简单版图中标出栅、多晶硅/有源区交叠、接触孔和互连。
3. 会计算方块电阻及平行板电容量级。
4. 会完整解释MOS网表中D-G-S-B节点顺序。
5. 知道LEVEL 1、BSIM3和PVT分析解决的不是同一个问题。
