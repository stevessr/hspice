# 计算方法专项：从题设到可检验的结果

本专题专门解释**如何计算**，与各章知识讲义和习题分离。所有公式都应先写明偏置定义、模型假设和单位，再推导结果。常见模型是长沟道LEVEL 1，真实BSIM3/PDK结果会有所不同。

## 1. 全局计算流程

1. **画图标注：** 节点名、G/D/S/B、电源及负载；对NMOS写 $V_{GS},V_{DS},V_{SB}$，PMOS写 $V_{SG},V_{SD}$。
2. **列已知量：** 电源、阈值、$\mu C_{ox}$、宽长比、$R,C,f$，先统一单位。
3. **选物理模型：** 长沟道平方律、带 $\lambda$ 的饱和模型、体效应、分布RC或真实SPICE模型。
4. **假设工作区：** 截止/线性/饱和，只在符合条件时套用对应公式。
5. **列方程：** 电流方程、输出节点KCL、能量/功率关系。
6. **求解并验算：** 去除虚根、负的非物理根或超电源的根，重新检验工作区。
7. **与仿真对照：** 用DC扫描验静态、TRAN验延迟、PVT验变化趋势。

## 2. 单位变换速查

| 常用量 | 单位关系 | 如何代数避免出错 |
|---|---|---|
| 长度 | $1\,\mu m=10^{-6}\,m$ | 同比 $W/L$ 可用相同μm |
| 电容 | $1\,fF=10^{-15}\,F$ | $k\Omega\cdot fF=ps$ |
| 电流 | $1\,\mu A=10^{-6}\,A$ | $\mu A/V^2$乘电压平方得μA |
| 延迟 | $1\,ns=1000\,ps$ | $k\Omega\cdot fF$的结果先是ps |
| 面积电容 | $1\,F/m^2=1000\,fF/\mu m^2$ | 厚度须以米代入SI式 |
| 功率 | $1\,\mu W=10^{-6}\,W$ | $V\times\mu A=\mu W$ |

## 3. MOS器件工作区和漏电流

对NMOS：

$$V_{OV}=V_{GS}-V_T,\qquad\beta_n=k'_n\,\frac{W}{L}.$$

| 条件（简化长沟道） | 状态 | 漏电流 |
|---|---|---|
| $V_{GS}\le V_T$ | 截止（忽略亚阈值） | $I_D\approx0$ |
| $V_{GS}>V_T,\ 0\le V_{DS}<V_{OV}$ | 线性区 | $\beta_n(V_{OV}V_{DS}-V_{DS}^2/2)$ |
| $V_{GS}>V_T,\ V_{DS}\ge V_{OV}$ | 饱和区 | $\beta_n V_{OV}^2/2$ |

对PMOS：用正的 $V_{SG}$、$V_{SD}$ 与 $|V_{Tp}|$，再计算漏源电流**大小**；同时明确SPICE电流方向约定。

**例：** $k'_n=200\,\mu A/V^2$，$W/L=4$，$V_T=0.4$ V，$V_{GS}=1.0$ V，$V_{DS}=0.2$ V。

$$\beta_n=800\,\mu A/V^2,\qquad V_{OV}=0.6\,V.$$

因 $0.2<0.6$，在线性区：

$$I_D=800(0.6\cdot0.2-0.2^2/2)=\boxed{80\,\mu A}.$$

若将 $V_{DS}$ 提高至0.8 V，则为饱和区，电流约

$$I_D=\frac{800}{2}(0.6)^2=\boxed{144\,\mu A}.$$

## 4. 阈值电压和体效应

$$V_T(V_{SB})=V_{T0}+
\gamma\left(\sqrt{2\phi_F+V_{SB}}-\sqrt{2\phi_F}\right).$$

前提是NMOS源—体结反向偏置且参数按上述形式定义。

**定压体偏例：** $V_{T0}=0.4$ V，$\gamma=0.45\sqrt V$，$2\phi_F=0.7$ V，$V_{SB}=0.5$ V：

$$V_T=0.4+0.45(\sqrt{1.2}-\sqrt{0.7})\approx\boxed{0.5165\,V}.$$

**传输高电平的自洽解法：** 栅极固定，传输输出也作为源端升高，不能先把体效应当常数。写

$$V_{out}=V_G-V_T(V_{SB}),\qquad V_{SB}=V_{out}-V_B,$$

再用二分法或牛顿法求唯一物理解，检查 $0\le V_{out}\le V_G$。

## 5. 电容、寄生RC和Elmore延迟

单位面积栅氧化层电容：$C_{ox}=\varepsilon_{ox}/t_{ox}$；本征面积尺度：$C_{ox}WL$。饱和区长沟道近似 $C_{gs,int}\approx(2/3)C_{ox}WL$，还应叠加栅源/栅漏重叠电容。

单阶集中RC电路的阶跃输出：

$$V_o(t)=V_{DD}(1-e^{-t/(RC)}),\quad t_{50\%}=(\ln2)RC\approx0.693RC.$$

注意输入有限上升时间和分布网络会改变实际50%延迟。

**两段RC例：** $R_1=R_2=5\,k\Omega$，$C_1=20\,fF$，$C_2=40\,fF$。

$$\tau_E=R_1(C_1+C_2)+R_2C_2
=5(60)+5(40)=\boxed{500\,ps}.$$

这是远端的一阶矩时间常数，不能无条件当成精确50%延迟。

## 6. 反相器静态KCL：电阻负载

电阻负载NMOS反相器：

$$I_R=\frac{V_{DD}-V_o}{R_L}=I_{Dn}(V_{in},V_o).$$

先假设NMOS在线性区，代入 $V_{GS}=V_{in}$、$V_{DS}=V_o$，解二次方程；舍去 $V_o<0$ 或 $V_o>V_{DD}$ 的根，确认 $0\le V_o<V_{in}-V_T$；否则换为饱和方程重新求解。

**例：** $V_{DD}=1.2$V，$V_T=0.4$V，$\beta_n=0.2\,mA/V^2$，$R_L=10\,k\Omega$，$V_{in}=1.2$V：

$$\frac{1.2-V_o}{10000}=0.0002(0.8V_o-V_o^2/2).$$

$$V_o^2-2.6V_o+1.2=0\Rightarrow V_o=0.6\,V\quad\text{或}\quad2.0\,V.$$

舍去2.0V，得到 $\boxed{V_{OL}=0.6\,V}$；$0.6<0.8$满足线性区。电源电流 $60\,\mu A$，静态功耗 $72\,\mu W$。

## 7. CMOS开关点和尺寸比

开关点定义为 $V_{in}=V_{out}=V_M$，两管平衡：

$$\frac{\beta_n}{2}(V_M-V_{Tn})^2
=\frac{\beta_p}{2}(V_{DD}-V_M-|V_{Tp}|)^2.$$

令 $r=\sqrt{\beta_p/\beta_n}$，得到

$$\boxed{V_M=\frac{V_{Tn}+r(V_{DD}-|V_{Tp}|)}{1+r}}.$$

当 $L_n=L_p$，要求 $\beta_n=\beta_p$：

$$\boxed{\frac{W_p}{W_n}=\frac{k'_n}{k'_p}}.$$

不应把典型3:1的宽度比当成任意工艺的精确最佳比例；要先查有效迁移率、真实工艺库和负载。

## 8. 噪声容限

输出高低电平 $V_{OH},V_{OL}$ 与输入噪声边界 $V_{IL},V_{IH}$ 必须分别确定：

$$NM_L=V_{IL}-V_{OL},\quad NM_H=V_{OH}-V_{IH}.$$

对于典型单调反相VTC，两处 $dV_{out}/dV_{in}=-1$ 的输入电压分别对应 $V_{IL},V_{IH}$。开关点 $V_M$ 则是VTC与 $V_{out}=V_{in}$ 的交点，**不是**斜率−1的点。

## 9. 延迟、功耗和尺寸优化

$$t_{pHL}\approx0.69R_nC_L,\quad
t_{pLH}\approx0.69R_pC_L,\quad t_p=(t_{pHL}+t_{pLH})/2.$$

串联多个反相器必须逐级交换沿方向，不能总是加同一种延迟。

$$P_\mathrm{dyn}=\alpha C_LV_{DD}^2f,\qquad
P_\mathrm{leak}=V_{DD}I_\mathrm{leak}.$$

这里 $\alpha$ 明确定义为每周期平均0→1充电次数。如果尺寸放大$s$倍，电阻约为$1/s$、输入电容约为$s$，**驱动后级更快的同时也拖慢前级**。

## 10. HSPICE计算结果怎么验

| 想验证什么 | 分析命令 | 波形/结果 |
|---|---|---|
| 直流工作点 | `.op` | 节点电压、静态电源电流 |
| $I_D$–$V_{GS}$ 和 $I_D$–$V_{DS}$ | `.dc` | 多条扫描曲线 |
| 反相器VTC | `.dc VIN 0 1.2 0.005` | $V(out)$ 对 $V(in)$ |
| 瞬态上升下降 | `.tran` | 50%交点 |
| 传播延迟 | `.measure tran ... TRIG ... TARG ...` | $t_{pHL},t_{pLH}$ |
| 动态功率/电源电流 | `.measure tran ... AVG i(VDD)` | 注意供电源电流符号 |
