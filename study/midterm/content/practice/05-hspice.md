# 实践五：HSPICE 网表、扫描与仿真排错

**对应资料：**实验一至九所用的 `.dc`、`.tran`、子电路和波形分析方法。

## 题 1 · DC 扫描变量（网表判读）

下面示例以实验一的器件结构为原型；模型路径需由实际环境提供：

```text
NMOS output family
.lib 'c18vmos001.lib' TT
.option post=2
Vd d 0 1.2
Vg g 0 1.2
Mn d g 0 0 N_18_LL L=0.2u W=0.4u
.dc Vd 0 1.2 0.01 Vg 0.4 1.2 0.2
.print dc I(Mn)
.end
```

1. 指出 NMOS 的 D、G、S、B 四个端口分别连接的节点。
2. 该 `.dc` 写法的横向快速扫描变量是什么？另一组参数的作用是什么？
3. 将 `.dc` 修改为以 $V_{GS}$ 为横轴、不同 $V_{DS}$ 为曲线族的写法。

## 题 2 · 反相器瞬态激励（设计）

假设已建立子电路 `.subckt INV in out vdd gnd`，并将其按相同端口顺序实例化，供电 $1.2\,\mathrm V$。

1. 写出一个周期 $20\,\mathrm{ns}$、高电平时间约 $10\,\mathrm{ns}$、上升/下降时间均 $0.1\,\mathrm{ns}$ 的 `PULSE` 输入源。
2. 给输出端接上 $1\,\mathrm{fF}$ 负载，指定瞬态分析从 0 到 $100\,\mathrm{ns}$。
3. 至少写出三个需要在波形查看器中对照的物理量。

## 题 3 · 模型与电流符号（诊断）

某同学看到 HSPICE 输出的 `I(VDD)` 为负值，便认为电源连接错误；又将型号为 `n15ll_mis_ckt` 的子电路实例写为 `Mn1`。

1. 解释电压源电流为负的可能原因。
2. 指出 `Mn1` 可能引起的模型调用问题，并写出正确的元件实例前缀。
3. 如果实际模型定义的端口顺序与标准 MOS 顺序不同，应该以哪一项为准？

## 题 4 · 初始条件与数值验证（分析）

给 NMOS 后接一个初值为零的电容，在瞬态仿真中观察节点 $x$。

1. 为什么 `.dc` 扫描不适于研究完整充电过程？
2. 写出初始条件设置及 `.tran` 分析的一种示意形式。
