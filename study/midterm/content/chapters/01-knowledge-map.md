# 知识结构与复习范围

## 九项实验与理论知识的对应

| **实验** | **主要内容**                            | **应达到的复习能力**                                      |
|:---------|:----------------------------------------|:----------------------------------------------------------|
| **实验** | **主要内容**                            | **应达到的复习能力**                                      |
| 实验一   | NMOS 的 $I_D-V_{DS}$、$I_D-V_{GS}$ 特性 | 判定截止、线性与饱和区，说明双重直流扫描；识别电流符号。  |
| 实验二   | PMOS 特性；NMOS 对电容充电              | 使用正确极性分析 PMOS；解释 NMOS 传输高电平的限制及终态。 |
| 实验三   | MOS 传输曲线；宽度变化                  | 分析 $V_X-V_{in}$ 曲线；利用 $W/L$ 比较驱动能力。         |
| 实验四   | 阈值电压、沟道长度调制、体效应          | 解释二极管连接、$\lambda$ 提取与 $\gamma$ 计算。          |
| 实验五   | 单源噪声、电阻负载反相器                | 用负载线确定工作点；定义噪声容限，辨析电阻负载功耗。      |
| 实验六   | CMOS 反相器与功耗                       | 认识五个工作阶段、传输特性、静态与动态功耗。              |
| 实验七   | CMOS 与非门、或非门                     | 绘制串并联上拉／下拉网络、真值表与传输特性。              |
| 实验八   | 异或、同或、二选一数据选择器            | 写布尔函数、真值表和选择关系，读出瞬态波形。              |
| 实验九   | SR 锁存器、主从 JK 触发器               | 分析状态保持、无效输入、时钟时序及一次锁存效应。          |

（资料对应：实验一—实验九；教材第 2—5 章。）

## 四个必须反复练习的能力

1.  **从电路确定物理量：**检查 D、G、S、B 的连接，先计算 $V_{\mathrm{GS}}$、$V_{\mathrm{DS}}$、$V_{\mathrm{SB}}$，再判断 MOS 状态。

2.  **从约束写方程：**例如饱和区使用电流模型，电阻负载使用 $I_R=(V_{\mathrm{DD}}-V_{out})/R$，负载电容使用 $I_C=C\,\mathrm dV/\mathrm dt$。

3.  **从逻辑函数画电路：**NMOS 下拉网络实现输出为 0 的条件，PMOS 上拉网络是其对偶网络。

4.  **从网表和曲线解释结果：**区分直流扫描与瞬态分析，识别电压轴、电流方向、工艺库、电源与尺寸参数。
