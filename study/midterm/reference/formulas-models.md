## 1. MOS 端口、几何和电容

| 目标 | 公式 | 单位 / 适用范围 | 原书位置 |
|---|---|---|---|
| 栅源电压 | $V_{GS}=V_G-V_S$ | V | §2.2—2.4 |
| 漏源电压 | $V_{DS}=V_D-V_S$ | V | §2.2—2.4 |
| 源体电压 | $V_{SB}=V_S-V_B$ | V | §2.3 |
| 过驱动 | $V_{OV}=V_{GS}-V_T$ | V | §2.4 |
| 氧化层单位面积电容 | $C_{ox}=\varepsilon_{ox}/t_{ox}$ | F/m² | §2.3 |
| 长沟道器件因子 | $\beta=\mu C_{ox}W/L$ | A/V² | §2.4 |
| 片阻 | $R_{\square}=\rho/t$ | Ω/□ | §3.2 |
| 均匀条状导线 | $R=R_{\square}\ell/w=\rho\ell/(wt)$ | Ω | §3.2 |
| 沟道电荷粗略数量级 | $Q_{ch}\sim C_{ox}WL V_{OV}$ | C，忽略局部分布 | §2.4 |

**符号歧义**：版图的 $\lambda$ 是抽象设计规则长度；电流模型的 $\lambda$ 是沟道长度调制参数，量纲为 V⁻¹。

## 2. MOS 电流、体效应及速度饱和

| 主题 | 公式 | 条件 | 原书位置 |
|---|---|---|---|
| NMOS 体效应 | $V_T=V_{T0}+\gamma(\sqrt{2\phi_F+V_{SB}}-\sqrt{2\phi_F})$ | NMOS、反向体偏置的一阶近似 | §2.3 |
| 长沟道线性区 | $I_D=\beta[(V_{GS}-V_T)V_{DS}-V_{DS}^2/2]$ | $V_{GS}\ge V_T,\ 0\le V_{DS}<V_{OV}$ | §2.4 |
| 长沟道饱和区 | $I_D=\beta(V_{GS}-V_T)^2/2$ | 忽略 CLM、长沟道 | §2.4 |
| 简化 CLM 模型 | $I_D\approx I_{D,sat}(1+\lambda V_{DS})$ | 近似处理饱和区漏压依赖 | §2.5 |
| 高场饱和漏压 | $V_{DSat}=\frac{V_{OV}E_cL}{V_{OV}+E_cL}$ | 教材高场速度饱和模型 | §2.5，式 (2.28) |
| α 次方律 | $I_D=K_s(W/L)(V_{GS}-V_T)^\alpha$ | 简化经验模型，需拟合 $K_s,\alpha$ | §2.6 |
| 亚阈值摆幅 | $S=dV_{GS}/d\log_{10}I_D$ | 常写作 mV/decade | §2.7 |
| 结电容近似 | $C_j(V)=C_{j0}/(1-V/\phi_0)^m$ | 根据结偏压与缓变系数 | §2.8 |

注意教材同时讨论长沟道与深亚微米高场模型，**不可混用饱和边界或假定一个电流公式通用所有章节**。

## 3. VTC、噪声和时序

| 主题 | 公式 | 适用说明 | 原书位置 |
|---|---|---|---|
| 高电平噪声容限 | $NM_H=V_{OH}-V_{IH}$ | 静态 VTC | §1.3、§4.3 |
| 低电平噪声容限 | $NM_L=V_{IL}-V_{OL}$ | 静态 VTC | §1.3、§4.3 |
| 反相器开关点 | $V_{out}(V_M)=V_M$ | 直流 VTC 与 $V_{out}=V_{in}$ 的交点 | §4.2 |
| 平均传播延迟 | $t_p=(t_{pHL}+t_{pLH})/2$ | 输入、输出各自的 50% 交点 | §1.3 |
| 一阶 RC 延迟 | $t_{50\%}\simeq(\ln 2)R_{eq}C_L$ | 单极点阶跃响应 | §1.3、§6.2 |
| 动态充放电功耗 | $P_{sw}=\alpha C_LV_{DD}^{2}f$ | $\alpha$ 采用每周期 0→1 次数定义 | §1.3 |

## 4. 工艺与尺寸如何影响结果

| 变化 | 一阶趋势 | 条件与限制 |
|---|---|---|
| NMOS W 增大 | 固定 L、偏置下 IDS 增大，输入电容也增加 | 仅相同工艺、模型和电压下比较 |
| L 增大 | 长沟道单位宽度电流减少 | 短沟道模型不能只按 W/L 预测 |
| tox 变薄 | Cox 增大 | 栅漏电与可靠性限制另算 |
| VGS 增大 | 导通电流通常增大 | 必须重新判断工作区域 |
| VSB 增大 | 对典型 NMOS，VT 增加 | 反向体偏置、指定模型 |
| CL 增大 | 传播延迟增大、切换能耗增大 | 驱动波形未严重改变 |
| PMOS 宽度增大 | 上升沿驱动通常增强 | 同时增大输入、扩散寄生 |
| 温度升高 | 迁移率常下降；漏电常增加 | 阈值与模型效应可能竞争 |

| KP | LEVEL 1 跨导参数 | A/V² | 不含实例 W/L |

## 6. HSPICE 四端顺序与基本仿真模板

教材 §3.4 第 82 页的 MOS 元件实例端子顺序为 **漏 D、栅 G、源 S、体 B**。这点在实际电路实例和波形理解中至关重要。

~~~spice
* 0.18 um N-device sample: illustrative, not a foundry PDK
.title nmos-ids-vds-sweep
.option post=2
VDD d 0 1.2
VGG g 0 0.9
M1 d g 0 0 NMODEL W=400n L=200n
.model NMODEL NMOS level=1 vto=0.4 kp=120u lambda=0.02
.dc VDD 0 1.2 0.02 VGG 0.6 1.2 0.2
.print dc V(d) I(VDD)
.end
~~~

这份示例使用自定义 LEVEL 1 模型，仅用于复现概念特性。若改用工艺库，需匹配库内器件类型及调用方式（原生 M 还是 X 子电路）；**上例数字不可当作教材某个 PDK 的晶体管参数**。

HSPICE 对电压源的电流正方向采用**流入电压源正端**的约定，因此当 VDD 给 NMOS 提供电流时，输出 I(VDD) 通常为负，要得到正的漏电流可画 −I(VDD)。具体语法参照仓库[HSPICE 速查](/content/appendices/c-hspice-quick-reference)与[网表讲义](/content/chapters/08-hspice-netlists)。
