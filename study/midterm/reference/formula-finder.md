# 教材公式检索与默写卡片

把教材原有的 [第 1—6 章公式表](/reference/formula-index) 和 [第 7—11 章公式表](/reference/formula-index-systems) 集中为一套可检索的复习卡片。

本页收录 **145 项精选公式及公式组**，包括原书编号等式、例题推导和图示归纳。每项保留**适用条件、原书式号、印刷页码及 PDF 页序**，并链接到对应 Typst 校对页面。

## 适合怎么复习？

1. **第一遍：对照公式理解条件。** 在搜索框输入“体效应”“速度饱和”“SRAM”“Elmore”或原书式号，定位需要复习的模型，再点击“教材对应页”看推导。
2. **第二遍：遮盖公式默写。** 勾选“默写模式”，只读公式名称与条件，写出关系式后点卡片显示答案。
3. **第三遍：检查能否选择正确模型。** 用[按题型速查与易错对照](/reference/exam-sheet)复盘线性/饱和区、长/短沟道、延迟与噪声容限，再去[专题实践题](/content/practice/)验证。

### 重要的两个区别

- **教材印刷页不是 PDF 页序**：以本扫描版为准，印刷第 *n* 页对应 PDF 第 *n+19* 页。这里的链接打开**可编辑 Typst 重排页**，而非原扫描图像。
- **编号公式不是所有推导式**：使用“教材编号公式”筛选原书明确编号的条目；“图示、例题及推导”是从现有复习材料整理出来的关联关系。原始表格会注明具体条件，不能把它们混成普适公式。
